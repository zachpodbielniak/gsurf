#+TITLE: gsurf CLI Reference
#+OPTIONS: toc:nil num:nil

* Usage

#+begin_example
gsurf [OPTIONS] [URI]
#+end_example

If no URI is given, the configured homepage is opened.

The positional argument is a URI or a filesystem path. Absolute paths, =./= and =../= paths, =~/= and =~user/= paths, relative paths that contain a slash and are not hosts, and the name of a file that exists in the working directory all open as =file://= URIs. =file:///path=, =file://localhost/path=, =file:/path=, and uppercase =FILE:= are accepted. Spaces and non-ASCII names are percent-encoded. A query or fragment on a =file:= URI is kept. A =file:= URI with a foreign host is not rewritten onto the local disk.

Any other scheme is passed through with its original spelling, including =http=, =https=, =about=, =data=, =mailto=, =javascript=, =view-source=, =gopher=, and =gemini=. A bare host such as =example.com= or =localhost:8080= gains =https://=. Other text is left for the search-engine module. The address bar uses the same rules.

#+begin_example
gsurf /usr/share/doc/index.html
gsurf ./page.html
gsurf ~/notes/index.html
gsurf file:///tmp/page.html#section
gsurf about:blank
#+end_example

* Options

| Option                   | Description                                           |
|--------------------------+-------------------------------------------------------|
| =-c, --config PATH=      | Use a specific YAML config file                       |
| =--c-config PATH=        | Use a specific C config file                          |
| =--no-yaml-config=       | Skip YAML loading (built-in defaults only)            |
| =--no-c-config=          | Skip C-config compilation/loading                     |
| =--no-modules=           | Do not load any modules                               |
| =--kiosk=              | Hide browser chrome; disable URL entry and new views |
| =--pwa=                | Install the URI as a kiosk desktop app and exit       |
| =--pwa-name NAME=      | App label; defaults to hostname; requires =--pwa=    |
| =-f, --fullscreen=       | Start in fullscreen                                   |
| =--generate-yaml-config= | Print the default YAML config and exit                |
| =--generate-c-config=    | Print the default C config and exit                   |
| =--list-modules=         | List available modules alphabetically and exit        |
| =-v, --version=          | Print version (and active backend) and exit           |

* Environment

| Variable             | Effect                                             |
|----------------------+----------------------------------------------------|
| =GSURF_MODULE_PATH=  | Directory to load modules from (overrides default) |
| =GSURF_CONFIG_C=     | Path to a C config file                            |
| =XDG_CONFIG_HOME=    | Base for =gsurf/config.yaml= and =config.c=        |
| =XDG_RUNTIME_DIR=    | Where the MCP module's Unix socket is created      |
| =GSURF_GVFS=         | FreeBSD only: =1= keeps GIO's GVfs module          |

On FreeBSD gsurf sets =GIO_USE_VFS=local= for itself before anything uses GIO (unless =GIO_USE_VFS= is already set or =GSURF_GVFS=1=). With GIO's GVfs client module active, the FreeBSD packages of gvfs 1.58, WebKitGTK 4.1 (2.46) and GLib 2.88 overwrite GTK's type data in any process that shows a =WebKitWebView= -- a minimal GTK program with only a web view too: gsurf showed a blank window and a stream of GTK criticals, and crashed outright with the AT-SPI accessibility bridge loaded. gsurf needs no GVfs mounts (=sftp://=, =smb://=, trash), and accessibility works.
