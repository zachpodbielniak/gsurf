#+TITLE: gsurf CLI Reference
#+OPTIONS: toc:nil num:nil

* Usage

#+begin_example
gsurf [OPTIONS] [URI]
#+end_example

If no URI is given, the configured homepage is opened.

The positional argument is a URI or a filesystem path. Absolute paths, =./= and =../= paths, =~/= and =~user/= paths, relative paths that contain a slash and are not hosts, and the name of a file that exists in the working directory all open as =file://= URIs. =file:///path=, =file://localhost/path=, =file:/path=, and uppercase =FILE:= are accepted. Spaces and non-ASCII names are percent-encoded. A query or fragment on a =file:= URI is kept. A =file:= URI with a foreign host is not rewritten onto the local disk.

Any other scheme is passed through with its original spelling, including =http=, =https=, =about=, =data=, =mailto=, =javascript=, =view-source=, =gopher=, and =gemini=. A bare host such as =example.com= or =localhost:8080= gains =https://=. Other text is left for the search-engine module. The address bar uses the same rules.

#+begin_example
gsurf /usr/share/doc/index.html
gsurf ./page.html
gsurf ~/notes/index.html
gsurf file:///tmp/page.html#section
gsurf about:blank
#+end_example

* Options

| Option                   | Description                                           |
|--------------------------+-------------------------------------------------------|
| =-c, --config PATH=      | Use a specific YAML config file                       |
| =--c-config PATH=        | Use a specific C config file                          |
| =--no-yaml-config=       | Skip YAML loading (built-in defaults only)            |
| =--no-c-config=          | Skip C-config compilation/loading                     |
| =--no-modules=           | Do not load any modules                               |
| =--kiosk=              | Hide browser chrome; disable URL entry and new views |
| =--pwa=                | Install the URI as a kiosk desktop app and exit       |
| =--pwa-name NAME=      | App label; defaults to hostname; requires =--pwa=    |
| =--list-pwa=           | List installed PWAs (id, name, scope, URL) and exit   |
| =--uninstall-pwa ID=   | Uninstall a PWA by its =--list-pwa= id and exit       |
| =-f, --fullscreen=       | Start in fullscreen                                   |
| =--lrg[=MODE]=          | Use the libregnum/raylib backend (=LRG_BACKEND=1= builds); see below |
| =--generate-yaml-config= | Print the default YAML config and exit                |
| =--generate-c-config=    | Print the default C config and exit                   |
| =--list-modules=         | List available modules alphabetically and exit        |
| =-v, --version=          | Print version (and active backend) and exit           |

* The libregnum backend: =--lrg=

#+begin_example
gsurf --lrg[=MODE[:ARRANGEMENT][:ENVIRONMENT]] [URI]
#+end_example

=--lrg= opens the page in a raylib window rendered by libregnum instead of a GTK window. It needs a build with =LRG_BACKEND=1=; otherwise gsurf exits with =--lrg requested but this build has no libregnum backend=. The value is optional, so it must be attached with an equals sign (=--lrg 3d= is =--lrg= followed by a URI).

| =MODE= | What opens |
|--------+------------|
| =2d= (default; a bare =--lrg=) | The flat libregnum window: the active tab drawn pixel-exact under a built-in address bar. |
| =3d= | The 3D tab space: every tab a live panel in a scene. Needs =LRG_3D=1= (the default with =LRG_BACKEND=1=); an =LRG_3D=0= build exits with =--lrg=3d needs a build with the libregnum scene=. |
| =3dvr= | Reserved: exits with =--lrg=3dvr is not implemented yet=. |

In 3D up to two more tokens follow, separated by =:= or =,=, in any order: one that names an environment (=studio=, =sky=, =workshop=, =cockpit=, =void=) sets the environment, any other sets the arrangement (=carousel=, =grid=, =free=, =single-panel=, =stack=). They override the =lrg:= config block. An unknown mode is a command-line error.

#+begin_example
gsurf --lrg https://example.org
gsurf --lrg=3d https://example.org
gsurf --lrg=3d:grid:sky https://example.org
gsurf --lrg=3d,sky,grid https://example.org
#+end_example

See [[file:lrg-3d.org][lrg-3d.org]] for the 3D tab space: arrangements, environments, reading mode, history depth, keys, the pointer and the =lrg.*= control methods.

* Environment

| Variable             | Effect                                             |
|----------------------+----------------------------------------------------|
| =GSURF_MODULE_PATH=  | Directory to load modules from (overrides default) |
| =GSURF_CONFIG_C=     | Path to a C config file                            |
| =XDG_CONFIG_HOME=    | Base for =gsurf/config.yaml= and =config.c=        |
| =XDG_RUNTIME_DIR=    | Holds =gsurf/<pid>-XXXXXX/=, the process's private runtime directory (temporary containers, working directory, the =control.sock= control socket), the =gsurf/<name>.sock= instance-name links, and the MCP module's Unix socket |
| =GSURF_INSTANCE=     | gsurfctl: the instance to talk to when =-i= is not given |
| =GSURF_GVFS=         | FreeBSD only: =1= keeps GIO's GVfs module          |

On FreeBSD gsurf sets =GIO_USE_VFS=local= for itself before anything uses GIO (unless =GIO_USE_VFS= is already set or =GSURF_GVFS=1=). With GIO's GVfs client module active, the FreeBSD packages of gvfs 1.58, WebKitGTK 4.1 (2.46) and GLib 2.88 overwrite GTK's type data in any process that shows a =WebKitWebView= -- a minimal GTK program with only a web view too: gsurf showed a blank window and a stream of GTK criticals, and crashed outright with the AT-SPI accessibility bridge loaded. gsurf needs no GVfs mounts (=sftp://=, =smb://=, trash), and accessibility works.

* Working directory

After parsing its options gsurf changes its working directory to its private runtime directory, =$XDG_RUNTIME_DIR/gsurf/<pid>-XXXXXX= (0700, removed at exit). WebKit's helper processes inherit the working directory, and some engine paths write files relative to it, so nothing can land in the directory gsurf was started from. Everything you give relative to that /launch directory/ still resolves against it: the URI argument (=gsurf page.html=), =--config= and =--c-config=, =$GSURF_MODULE_PATH=, relative paths in the config files (=cookie_jar=, =data_dir=, =cache_dir=, module files and directories such as =downloads.dir=), and a relative path typed into the address bar. If the runtime directory cannot be created, gsurf warns and stays where it was started.

* Driving a running gsurf: gsurfctl

=gsurf URL= always starts a new browser process. To act on one that is already running — open a tab in it, list its tabs, read the page, run an action, split a wmux pane — use =gsurfctl=, which talks to the control socket every gsurf opens (=control.enabled=, on by default):

#+begin_example
gsurfctl open https://example.org --bg
gsurfctl tabs
gsurfctl -i work wmux 'split-window -h'
#+end_example

=gsurfctl -i= picks an instance by pid or by =control.name=; without it gsurfctl takes =$GSURF_INSTANCE=, the only instance, or the most recently focused one. See [[file:gsurfctl.org][gsurfctl.org]] and [[file:control.org][control.org]].
