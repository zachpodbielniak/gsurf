#+TITLE: gsurf Module System
#+OPTIONS: toc:2 num:nil

* Concept

Each surf "patch" is a runtime-loaded =.so= module. A module is a =GsurfModule=
subclass that implements one or more hook-point GInterfaces. =GsurfModuleManager=
loads modules from the module directory (=$GSURF_MODULE_PATH=, then
=<exe-dir>/modules= in a dev tree, then the installed =MODULEDIR=), reads each
module's =enabled:= flag and options from the YAML =modules:= map, activates the
enabled ones, and dispatches hooks in priority order.

* Anatomy of a module

#+begin_src c
#include <gsurf/gsurf.h>
#include <gmodule.h>

#define GSURF_TYPE_FOO_MODULE (gsurf_foo_module_get_type())
G_DECLARE_FINAL_TYPE(GsurfFooModule, gsurf_foo_module, GSURF, FOO_MODULE, GsurfModule)

struct _GsurfFooModule { GsurfModule parent_instance; /* state */ };

static void gsurf_foo_uri_handler_init(GsurfUriHandlerInterface *iface);

G_DEFINE_FINAL_TYPE_WITH_CODE(GsurfFooModule, gsurf_foo_module, GSURF_TYPE_MODULE,
    G_IMPLEMENT_INTERFACE(GSURF_TYPE_URI_HANDLER, gsurf_foo_uri_handler_init))

/* hook vfuncs ... */

static const gchar *gsurf_foo_get_name(GsurfModule *m) { return "foo"; }
static void gsurf_foo_configure(GsurfModule *m, gpointer config_ptr) {
    GsurfConfig *config = config_ptr;
    YamlNode *node = gsurf_config_get_module_node(config, "foo");
    /* parse node ... */
}

static void gsurf_foo_module_class_init(GsurfFooModuleClass *k) {
    GsurfModuleClass *mc = GSURF_MODULE_CLASS(k);
    mc->get_name = gsurf_foo_get_name;
    mc->configure = gsurf_foo_configure;
    /* mc->activate / mc->deactivate / mc->get_description ... */
}
static void gsurf_foo_module_init(GsurfFooModule *self) { }

G_MODULE_EXPORT GType gsurf_module_register(void) { return GSURF_TYPE_FOO_MODULE; }
#+end_src

Build it by copying =modules/search_engines/Makefile= (the module name is derived
from the directory). Add an =enabled:= block under =modules:= in
=data/default-config.yaml= and a row in =builtin_modules[]= in =src/main.c=.

* Hook-point interfaces (src/interfaces/)

| Interface              | vfunc(s)                                  | Fired when / used by                          | Consumable        |
|------------------------+-------------------------------------------+-----------------------------------------------+-------------------|
| =GsurfInputHandler=    | =handle_key_event=, =handle_mouse_event=  | key/button before default binds (modal, tabs) | first TRUE wins   |
| =GsurfKeybindProvider= | =list_keybinds=                           | =?= help overlay; queried at display time     | additive          |
| =GsurfActionHandler=   | =handle_action=                           | a core keybind action with no built-in implementation (open-prompt → chromebar, find → find_bar, tab-* → tabs, follow-hints → modal) | first TRUE wins |
| =GsurfUriHandler=      | =rewrite_uri=                             | URI about to load (search engines, bookmarks) | first non-NULL    |
| =GsurfNavigationHook=  | =before_navigate=, =after_navigate=, =load_changed=, =decide_main_response= | navigation lifecycle (history, homepage, containers); =before_navigate= also fires for iframe navigations and popup requests, =decide_main_response= only for the main frame's displayable response | =before=, =decide_main_response=: veto |

More interfaces (request-filter, download-handler, status-provider,
script-injector, permission-handler, cert-handler, context-menu-provider,
render-overlay, setting-provider, keybind-provider) follow the same
=G_DECLARE_INTERFACE= + manager-dispatch pattern and are added as their modules
are implemented.

** Web-process extensions

Some work has to happen inside the engine's web process, next to the page (rewriting a sub-resource request, running script before the page's own). A module ships such a shared object next to its =.so= and registers it from =configure()=, before the first view exists:

#+begin_src c
gsurf_web_process_extension_register("adblock", "/path/to/adblock-webext/gsurf-adblock-webext.so",
	init_data);   /* any GVariant; delivered under the "adblock" key */
#+end_src

The WebKit backends hand every registered extension, and an =a{sv}= of each one's data, to each web process they launch. The registry itself (=src/core/gsurf-web-process.h=) is backend-agnostic. =modules/adblock/webext/= is the reference; =modules/hardening/webext/= is a smaller one whose decision logic is a GLib-only file shared with the module and its unit test.

A module that owns a UI a core action refers to should implement =GsurfActionHandler::handle_action= and answer that =GsurfAction=. The host's keymap only knows the action (=o= → =open-prompt=); it calls =gsurf_module_manager_dispatch_action()= when it has no built-in implementation, and the first active module in priority order that returns =TRUE= performs it. That keeps the binding in the user's =keybinds:= table while the module stays free to own its widget.

Priority is read when dispatching: the manager sorts its modules before activating them and again afterwards, so a priority set inside =activate()= (=modal= claims =GSURF_PRIORITY_HIGHEST=) takes effect.

A module that owns keys should implement =GsurfKeybindProvider::list_keybinds=
and append =GsurfKeybindHelp= rows with its *current* configured keys. The =?=
overlay calls =gsurf_module_manager_collect_keybinds()= on each press, so
disabled modules and reconfigured keys show up without a restart.

Note on =GsurfScriptInjector::inject(view, uri)=: it fires *once per view, at
view construction* (with =uri = NULL=) — it is not re-dispatched per page load.
A user script added there with =gsurf_view_add_user_script()= persists and is
re-run by WebKit on every navigation automatically, so document-start bootstrap
JS (and any =WebKitUserContentManager= script-message handler registered from
=inject=) only needs to be set up once.

* Lifecycle

=configure(config)= → (manager reads =enabled=) → =activate()= if enabled →
hooks dispatched while =is_active= → =deactivate()= on shutdown. Set hook
priority with =gsurf_module_set_priority()= (lower runs first).

*Input mode (since 0.4.2).* The module that owns the keyboard modes (=modal=) publishes the current one with =gsurf_module_manager_set_mode()=; chrome follows =GsurfModuleManager:mode= / =mode-changed= (the chromebar's and wmux's mode indicators). =gsurf_mode_policy_get_label()= gives the indicator text (=NORMAL=, =INSERT=, =FOLLOW=, ...). It is separate from the input passthrough flag (=gsurf_module_manager_set_input_passthrough()=), which still decides whether bare keys bypass the modules.

* Shared helpers for modules (src/util/)

Per-site configuration and private state follow one pattern across modules; use these instead of re-implementing them.

** =GsurfHostRules= (=util/gsurf-host-rules.h=)

An ordered list of case-insensitive regular expressions matched against the bare host (=www.example.com=, no scheme or port), each with an optional YAML mapping of settings. Patterns are not anchored implicitly: write =(^|\.)example\.com$= for a domain and its subdomains.

- =gsurf_host_rules_load(rules, node, "match", &error)= reads a YAML list. Each element is either a bare pattern string (a rule with no settings) or a mapping whose =match= member is the pattern; the whole mapping is the rule's data. A bad pattern or element shape fails with =GSURF_HOST_RULES_ERROR=; load into a fresh object and swap it in on success to keep a second =configure()= all-or-nothing.
- =gsurf_host_rules_find()= / =_matches()= / =_lookup()= return the first match; =_lookup_all()= returns the data of every match in order for modules that merge settings (later rules win).
- =gsurf_host_rules_to_json()= produces =[{"pattern": …, "data": {…}|null}]= for rules evaluated inside the page. Keep such patterns to the syntax PCRE and JavaScript share (no lookbehind, possessive quantifiers or =(?P<…>)=).
- =gsurf_host_rules_to_variant()= produces =a(sa{sv})= for web-process extensions: scalars keep their type (=s=, =x=, =d=, =b=), scalar lists become =as=, anything nested travels as JSON text.
- =gsurf_host_from_uri()= gives the lowercase host of a network URI (or =NULL= for =about:=, =data:=, =file:=, …), the value every lookup takes.

** Private files (=util/gsurf-private-file.h=)

- =gsurf_private_mkdir()= creates directories 0700.
- =gsurf_private_write()= replaces a file atomically at mode 0600, creating its parent 0700 first. A file that already exists with looser permissions is tightened to 0600 before it is replaced (GLib would otherwise keep its old mode).
- =gsurf_private_file_is_private()= checks a file is a regular file owned by the user with no group/other access, before trusting sensitive data in it (for example autofill card data).
- =gsurf_expand_home()= expands a leading =~/= in configured paths.
