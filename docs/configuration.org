#+TITLE: gsurf Configuration
#+OPTIONS: toc:2 num:nil

* Files and order

Configuration is merged in this order (later overrides earlier):

1. Built-in defaults (embedded =data/default-config.yaml=).
2. =$XDG_CONFIG_HOME/gsurf/config.yaml= (or =--config PATH=, or =/etc/gsurf/config.yaml=).
3. =$XDG_CONFIG_HOME/gsurf/config.c= compiled and run (see [[file:c-config.org][C configuration]]).

Generate a starting point:

#+begin_src sh
gsurf --generate-yaml-config > ~/.config/gsurf/config.yaml
gsurf --generate-c-config   > ~/.config/gsurf/config.c
#+end_src

* Core sections

#+begin_src yaml
browser:
  homepage: "about:blank"
  new_view_uri: "about:blank"
  default_zoom: 1.0
  smooth_scroll: true
  fullscreen_on_start: false

user_agent: ""                 # "" = engine default

webkit:                        # web engine defaults (surf defconfig analogue)
  javascript: true
  images: true
  webgl: false
  webrtc: false
  media_stream: false
  caret_browsing: false
  developer_extras: false
  default_font_size: 16
  default_charset: "UTF-8"
  # ... see --generate-yaml-config for the full list

window:
  title: gsurf
  geometry: 1024x768

keybinds:                      # "Mods+Key" -> action (see keybindings.org)
  "Ctrl+r": reload
  "Alt+Left": back
  "j": scroll-down

modules:                       # one block per module; `enabled:` gates it
  search_engines:
    enabled: true
    default: ddg
    engines:
      g: { prefix: "g ", url: "https://www.google.com/search?q=%s" }
  mcp:
    enabled: false
    # ...
#+end_src

GTK3, GTK4, and LRG apply =webkit.webrtc= to the engine on each settings update. Enabling WebRTC also enables media streams, as required by WebKit, even when =webkit.media_stream= is false. With WebRTC disabled, =webkit.media_stream= controls media streams independently.

An empty =user_agent= (or =NULL= in C settings) restores the engine's default user agent, including after a per-URI user-agent override stops matching. This reset applies to all three backends.

Native settings regressions run with =make test-gui= under Xvfb. On an existing display, run =GSURF_TEST_GUI=1 ./build/release/test-backend-settings= after =make test=; ordinary headless tests skip these display-dependent checks.

The =modules:= map is parsed by the core for the =enabled:= flag; each module
reads its own options from its section (=gsurf_config_get_module_node=).

The =tabs= section configures the tab strip and the tree sidebar (=position=, =show_single=, the =bg_color= / =active_color= / =fg_color= colours, =sidebar=, =sidebar_position=, =sidebar_width=, =sidebar_hides_strip=, =indent=, =max_depth=, =on_close_parent= and the =key_*= bindings); [[file:tabs.org][tabs.org]] has the full reference with defaults and validation rules.

Sections that map to surf concepts: =search_engines= (searchengines patch),
=uri_params= (=uriparams[]=), =site_styles= (=styles[]=), =cert_pins= (=certs[]=).

=dark_mode= takes a global =mode= (=off=, =native=, =filter=, =dynamic=; legacy =auto=, =light=, =dark= still work), =brightness=/=contrast=/=sepia=/=grayscale=, =key_toggle=/=key_toggle_site=, and a =sites:= list of per-host rules; runtime per-site toggles are saved in =$XDG_DATA_HOME/gsurf/dark_mode/sites.yaml=. The full reference is in [[file:dark-mode.org][Dark mode]].

* Form autofill (=form_autofill=)

#+begin_src yaml
modules:
  form_autofill:
    enabled: false
    file: ~/.config/gsurf/autofill.yaml   # optional; this path is the default
    suggest_on_focus: true
    key_fill: "Ctrl+Alt+f"
    exclude: ['(^|\.)paypal\.com$']
    profiles:
      - label: home
        given_name: Zach
        email: zach@example.org
        street: ["742 Evergreen Terrace", "Apt 9"]
        country: US
#+end_src

Profiles come from =file= (a mapping with a =profiles= list) and from the inline =profiles= list. An inline profile with the label of a file profile overrides that profile field by field; new labels are appended; a label repeated within one source replaces the earlier one with a warning. Card data (=cc_name=, =cc_number=, =cc_exp=) is accepted only from the file, and only when it is private (=chmod 600=, owned by you, not a symlink); otherwise the card data is refused with a warning on stderr and the rest of the file is used. =cc_csc= is never stored. Malformed values (a card number failing the Luhn check, a bad expiry, an e-mail without =@=, a country that is not an ISO alpha-2 code, ...) are dropped field by field with a warning that never contains the value; unknown keys warn. An invalid =exclude= rule disables autofill on every host until fixed. The full schema, classification order, suggestion UI and security model are in [[file:form-autofill.org][form-autofill.org]].
